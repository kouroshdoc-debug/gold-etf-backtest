# Gold ETF Backtest

پژوهش بازتولیدپذیر صندوق طلای لوتوس («طلا») بر مبنای تاریخچه روزانه TSETMC.

| نسخه | تعریف |
|---|---|
| V0 | خرید و نگهداری |
| V1 | فیلتر روند؛ قیمت پایانی بالاتر از SMA |
| V2 | RSI(2) قیمت پایانی |
| V3 | RSI(2) آخرین معامله |
| V4 | RSI(2) قیمت پایانی + فیلتر روند |
| V5 | V4 + انحراف آخرین معامله از قیمت پایانی |

سیگنال در پایان روز ساخته و در قیمت بازشدن روز معاملاتی بعد اجرا می‌شود. خروج نسخه‌های بازگشت به میانگین پس از عبور قیمت از SMA5 است. شبکه حساسیت RSIهای 5/10/15 و SMAهای 150/200/250 را بررسی می‌کند.

```bash
pip install -r requirements.txt
python src/download_tsetmc.py
python src/backtest.py
```

خروجی‌ها: خلاصه V0–V5، معاملات، حساسیت، آزمون برون‌نمونه، Walk-Forward و معیار تصادفی هم‌مدت. این پژوهش توصیه خرید یا فروش نیست.

## مرحلهٔ ۳: اعتبارسنجی مستقل و بازده نقد تاریخی

نسخه‌های V2 و V3 با پارامترهای اولیهٔ ثابت (`RSI(2)<10` و خروج `SMA5`) روی صندوق‌های دیگر اجرا می‌شوند؛ دادهٔ صندوق جدید برای انتخاب پارامتر مصرف نمی‌شود. معیارهای قبولی پیش از مشاهدهٔ نتیجه در `config.json` ثبت شده‌اند. نخستین مجموعهٔ مستقل «عیار» است. دانلود مستقیم TSETMC در اولویت است و در صورت عدم دسترسی Runner، فقط آینهٔ پین‌شده با SHA مشخص استفاده می‌شود؛ منشأ در artifact ثبت خواهد شد.

```bash
python src/download_validation.py
python src/multi_asset_validation.py
```

برای آزمون واقعی بازده وجه نقد، فایل `data/cash_annual_rate.csv` با ستون‌های `date,annual_rate` لازم است. نرخ تا تاریخ مشاهدهٔ بعدی به جلو حمل می‌شود. اگر فایل وجود نداشته باشد، برنامه صریحاً نتیجهٔ تاریخی تولید نمی‌کند و نرخ‌های ثابت ۰/۲۰/۳۰/۴۰ درصد صرفاً سناریوی حساسیت باقی می‌مانند.

### ورودی رسمی صندوق‌های اعتبارسنجی

فایل‌های خام رسمی TSETMC را می‌توان بدون تغییر کد در مسیرهای زیر قرار داد. فایل کامل یا قطعات متنی با پسوند `.part-00`، `.part-01` و ... پذیرفته می‌شود:

```text
data/official/ayar.json
data/official/gohar.json
data/official/kahroba.json
```

ترتیب منبع: TSETMC زنده ← snapshot رسمی مخزن ← آینهٔ پین‌شده (فقط در صورت تعریف). نبود داده باعث جعل یا جایگزینی خاموش نمی‌شود؛ نماد با وضعیت `missing` ثبت خواهد شد.

`src/promotion_gate.py` یک دروازهٔ بسته‌پیش‌فرض است. حداقل سه صندوق مستقلِ قبول‌شده با دادهٔ رسمی و دادهٔ تازهٔ صندوق اصلی برای ارتقا به `PAPER_WATCH_CANDIDATE` لازم است. در همهٔ حالات `execution_authorized=false` باقی می‌ماند و هیچ سفارش واقعی ارسال نمی‌شود.
